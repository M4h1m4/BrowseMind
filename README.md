# BrowseMind

A computer-use automation system that records LLM-driven browser sessions as reusable capabilities and replays them deterministically against legacy web applications.

## How it works

**Capture** — given a natural-language goal and a target URL, BrowseMind opens a real browser, takes a screenshot at each step, and asks an LLM (GPT-4o-mini) to decide the next action. The agent executes the action, extracts DOM element data at the interaction point, and repeats until the goal is complete. The full session is saved as a typed, versioned artifact in SQLite.

**Replay** — the saved artifact is replayed deterministically against the same application. Each step uses the captured DOM selectors (aria-label, placeholder, text content, coordinates as fallback) to locate and interact with elements, and verifies a checkpoint condition before proceeding to the next step.

## Architecture

```
POST /api/v1/capture/run
        │
        ▼
  runDiscovery()          ← Playwright browser + GPT-4o-mini
        │
   per step:
   screenshot → LLM → action → execute → DOM extract → ArtifactBuilder
        │
        ▼
  saveArtifact()          ← SQLite (better-sqlite3)
  writeRunLog()           ← evidence/runs/<runId>.json

POST /api/v1/replay/run
        │
        ▼
  Artifact loaded from SQLite → deterministic step execution
```

## API

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/v1/capture/run` | Start a capture run |
| `POST` | `/api/v1/replay/run` | Start a replay run from an artifact |
| `GET`  | `/api/v1/runs/:runId/status` | Poll run status and outputs |
| `POST` | `/api/v1/runs/:runId/resume` | Resume a paused run after human handoff |
| `POST` | `/api/v1/runs/:runId/takeover` | Signal human is taking over the session |
| `GET`  | `/api/v1/artifacts?tenantId=` | List artifacts for a tenant |
| `GET`  | `/api/v1/artifacts/:artifactId` | Get a specific artifact |
| `DELETE` | `/api/v1/artifacts/:artifactId` | Delete an artifact |

### Capture request body

```json
{
  "goal":      "Search for employee John Doe and return their ID",
  "targetApp": "https://your-app.example.com",
  "tenantId":  "tenant-001"
}
```

### Run status response

```json
{
  "runId":       "uuid",
  "status":      "running | success | failed | login_required | human_in_control",
  "currentStep": 4,
  "outputs":     null,
  "error":       null
}
```

## Artifact schema

Each captured session is stored as an artifact:

```
Artifact
  artifactId   string
  goal         string
  targetApp    string
  tenantId     string
  version      number
  allowWrites  boolean
  createdAt    string (ISO 8601)
  steps[]
    stepNumber        number
    actionType        click | input | navigate | wait | scroll | keydown
    targetDescription string
    value             string | undefined
    reasoning         string
    elementData
      primary    { type: aria-label,   value }
      secondary  { type: placeholder,  value }
      tertiary   { type: text-content, value }
      fallback   { type: coordinates,  value: { x, y } }
    checkpoint
      type   url-contains | element-visible | text-present
      value  string
```

Checkpoints are generated by the LLM from the observed post-action state — the agent looks at the screenshot after executing a step and labels what on the page proves that step succeeded.

## Getting started

### Prerequisites

- Node.js 20+
- Docker (optional, for containerized test runs)

### Setup

```bash
git clone https://github.com/M4h1m4/BrowseMind.git
cd BrowseMind
npm install
npx playwright install chromium
cp .env.example .env
# Add your OPENAI_API_KEY to .env
```

### Run the server

```bash
npm run dev
```

Server starts on `http://localhost:3000`.

### Run tests

```bash
# Unit + integration (no browser, no API key needed)
npm run test:ci

# Unit + integration inside Docker
docker compose run --rm test

# End-to-end (real browser + real OpenAI calls)
RUN_E2E=true npm run test:e2e
```

## Environment variables

| Variable | Required | Description |
|----------|----------|-------------|
| `OPENAI_API_KEY` | Yes (capture) | OpenAI API key |
| `PORT` | No | HTTP server port (default: 3000) |
| `MAX_STEPS_CAPTURE` | No | Max steps per capture run (default: 25) |
| `DATABASE_PATH` | No | SQLite path (default: `db/artifacts.db`, use `:memory:` for tests) |

## Tech stack

- **Runtime** — Node.js, TypeScript, Express
- **Browser automation** — Playwright (Chromium)
- **LLM** — OpenAI GPT-4o-mini via function calling
- **Database** — SQLite via better-sqlite3
- **Tests** — Jest, Supertest
- **Containerization** — Docker
